# ADR-007. Данные на сервере и изоляция семей

**Статус:** заготовка — решение ещё не записано.

## О чём

Как устроены таблицы на сервере и как одна семья не видит данные другой.

## Что отразить

- Таблицы: повторяют текущие таблицы Dexie плюс аккаунты и служебные
- У каждой строки семьи: `family_id`, серверная `version`, `createdAt`, `updatedAt`, пометка удаления
- `family_id` берётся только из сессии, никогда из тела запроса
- Защита строк в Postgres (RLS) вторым рубежом: `set_config` в начале транзакции, роль приложения без `BYPASSRLS`
- Тесты изоляции семей
- Миграции в два шага: сначала добавить, потом убрать старое отдельным релизом
- Инварианты: снимки цен, приз за серию — строка `spends` с `source: 'streak'`
- Схемы сервисов: `core` у `api`, `notifications` у Notifications
