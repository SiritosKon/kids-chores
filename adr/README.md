# ADR — архитектурные решения

Здесь фиксируем принятые решения по архитектуре фронта и бэка, коду и безопасности. Основа —
ресерчи из `research/`. Инфраструктура (хостинг, контуры, наблюдаемость) и юридические вопросы
сюда не входят.

Каждый ADR: контекст → решение → рассмотренные варианты → последствия. Статусы: «заготовка»,
«предложен», «принят», «заменён ADR-N». Принятый ADR не правим — меняем новым.
