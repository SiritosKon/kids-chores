# ADR-003. Архитектура фронта

**Статус:** заготовка — решение ещё не записано.

## О чём

Закрепляем то, что уже работает во фронте, и добавляем правила на время появления бэкенда.

## Что отразить

- FSD: слои, импорт только вниз, вход в слайс через `index.ts`, `@x` между сущностями
- Запросы к API — только в `entities/*/api`, остальные слои про сеть не знают
- Dexie — рабочая копия данных на устройстве, главная копия — на сервере
- zod на границах: IndexedDB, импорт JSON, ответы API; схемы чтения снисходительны к старым записям
- Снимки: `completions.points` и `spends.cost` не переписываются
- Баланс, серии и бейджи вычисляются из истории, не хранятся
- Схемы запросов и ответов импортируются из `packages/contracts`
