# ADR-004. Работа без сети и синхронизация

**Статус:** заготовка — решение ещё не записано.

## О чём

Есть сеть — работаем с сервером, нет сети — с локальными данными и очередью, при появлении сети отправляем очередь и забираем свежее состояние. Фиксируем политику конфликтов и правила, на которых она держится.

## Что отразить

- Онлайн: запись на сервер, локальная база — кеш; офлайн: локальная база + очередь; сеть появилась: очередь → сервер → свежее состояние
- Этап 1 — одно устройство: первичная выгрузка, отправка изменений, восстановление на новом устройстве
- Этап 2 — несколько устройств: забираем чужие изменения при открытии и возврате в приложение
- Политика конфликтов (решено): каталог и настройки — слияние по полям, в одном поле побеждает пришедшее последним; покупка при нехватке баланса — принимаем, баланс в минус, пометка родителю; двойная отметка — одна; отметили/сняли — последнее действие; удаление против правки — правка восстанавливает из архива
- Правила: свой id у каждого изменения, отправка изменённых полей, серверная нумерация, пометка удалённого, id отметки из ребёнка, задачи и дня, день по часовому поясу семьи, сервер отклоняет только некорректные данные
- Почему своя очередь, а не Dexie Cloud, RxDB, PowerSync и др.
- Переезд с `siritoskon.github.io`: данные переносим вручную через экспорт JSON
