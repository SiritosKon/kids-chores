# ADR-004. Работа без сети и синхронизация

**Статус:** заготовка — решение ещё не записано.

## О чём

Приложение работает без сети, изменения уходят на сервер через очередь на устройстве. Фиксируем этапы и правила, которые закладываем сразу, чтобы этап 2 не потребовал переделки.

## Что отразить

- Как работает очередь изменений в Dexie
- Этап 1 — одно устройство: первичная выгрузка, отправка изменений, восстановление на новом устройстве
- Этап 2 — несколько устройств: забираем чужие изменения при открытии и возврате в приложение
- Правила: свой id у каждого изменения, серверная нумерация, пометка удалённого, id отметки из ребёнка, задачи и дня, кто побеждает при конфликте, день по часовому поясу семьи, отказ сервера
- Почему своя очередь, а не Dexie Cloud, RxDB, PowerSync и др.
- Переезд с `siritoskon.github.io`: данные переносим вручную через экспорт JSON
