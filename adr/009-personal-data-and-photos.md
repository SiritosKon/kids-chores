# ADR-009. Минимум персональных данных и фото

**Статус:** заготовка — решение ещё не записано.

## О чём

Что сервер знает о семье и где хранятся изображения. Фото детей не собираем — набор аватарок.

## Что отразить

- Что храним и чего не храним: хеш идентификатора, без email, имени, телефона родителя
- Логи без IP и User-Agent
- Имена детей, каталог и история — на сервере в открытом виде (решено): сервер сливает конфликты и работает с данными; защита — изоляция семей, шифрование дисков, логи без ПДн
- Фото детей не загружаем (решено): набор аватарок в сборке фронта, `avatarId` вместо `photo`, старые фото не отправляются на сервер; делаем вместе с бэкендом
- Картинки вариантов наград (решено): загрузка по подписанной ссылке в хранилище контура, раздача через CDN (EU — Hetzner Object Storage + Cloudflare, RU — Yandex Object Storage + Cloud CDN), случайные имена файлов
- Обработка фото на устройстве: удаление EXIF (в том числе GPS), JPEG вместо WebP в Safari
