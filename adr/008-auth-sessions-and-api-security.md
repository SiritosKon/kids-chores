# ADR-008. Вход, сессии и защита API

**Статус:** заготовка — решение ещё не записано.

## О чём

Вход через провайдера контура, сессии на сервере, родрежим на общем устройстве и базовая защита API.

## Что отразить

- Провайдеры: RU — Яндекс ID, EU — Google; своих паролей, email-кодов и SMS нет
- Минимальные права у провайдера, храним только хеш идентификатора
- Свой модуль входа (Identity) вместо Better Auth и отдельного сервера входа
- Сессии: на сервере в Valkey, в браузере — cookie `httpOnly; Secure; SameSite=Lax`, API на том же сайте
- iOS: у PWA и Safari раздельные cookie — передача входа одноразовым кодом
- PIN родрежима: хеш вместо открытого текста, лимит попыток, сброс через повторный вход
- Защита API: ограничение частоты запросов, проверка `Origin`, CSP и заголовки безопасности
- Секреты по контурам, CI без долгоживущих ключей
