# Архитектура фронта — Feature-Sliced Design

Правила работы с репозиторием — в `CLAUDE.md` в корне. Здесь — карта: что где лежит.

Слои сверху вниз, импорт разрешён только вниз; внутри слоя — нет.

| Слой | Что лежит | Слайсы |
|---|---|---|
| `app` | Точка сборки: провайдеры (pinia, Quasar), глобальные стили, корневой `App.vue` | — |
| `pages` | Экраны целиком | `home` |
| `widgets` | Самостоятельные композиции экрана | `tasks-board`, `goal-meter-board`, `rewards-panel`, `parent-menu` |
| `features` | Действия пользователя | `parent-login`, `select-date`, `award-reward`, `rollback-spend`, `wallet-history`, `whats-new`, `backup` |
| `entities` | Предметные сущности: схема, состояние, доступ к данным | `child`, `task`, `reward`, `completion`, `spend`, `wallet`, `app-version`, `parent-session` |
| `shared` | Код без привязки к предметной области | `api`, `lib`, `ui`, `assets` |

Сегменты внутри слайса: `ui` — вёрстка, `model` — состояние и логика, `api` — доступ к данным,
`lib` — чистые помощники, `config` — константы. Обязательных нет, берётся нужный.

## Состояние

Доменное состояние — в `entities/*/model` (`wallet`, `parent-session`), состояние действий —
в `features/*/model` (`select-date`, `whats-new`). Общей папки `stores/` нет намеренно: это
группировка по техническому виду вместо группировки по смыслу.

## Межсущностные связи

Сущность не импортирует сущность. Единственное исключение оформлено через `@x`: папка с файлом
на каждого конкретного потребителя.

```
entities/completion/
  index.ts        публичный API для слоёв выше
  @x/wallet.ts    отдельный вход, открытый лично для entities/wallet
```

Так связь объявлена, а не случилась: открыв `@x`, видно исчерпывающий список зависимых сущностей,
и поверхность доступа узкая. Сейчас таких входов два — `completion/@x/wallet` и `spend/@x/wallet`,
оба потому, что баланс по определению считается по отметкам и списаниям.

## Приход бэкенда

Точка подмены — `entities/*/api`. Репозитории меняют реализацию с Dexie на HTTP, схемы остаются
теми же (ими же валидируем ответы сервера), UI не трогаем.
