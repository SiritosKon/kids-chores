# Фаза 1 — Роадмап на сегодня (локальная реализация, без бэка)

Улучшения текущего MVP, которые делаем **на фронте + IndexedDB**, не поднимая сервер.
Приоритеты: P0 — ценность/риск высокие, делаем первыми; P1 — важно; P2 — приятно.

## P0 — данные и надёжность

- [ ] **Сброс/очистка данных** — действие в родрежиме «очистить всё» и «очистить неделю у ребёнка» (кнопку недельного сброса мы убирали — вернуть под родрежим).
- [ ] **Валидируемый импорт + слияние** — сейчас импорт заменяет всё; добавить проверку версии схемы и режим «заменить / дополнить».
- [ ] **Напоминание о бэкапе** — мягкий баннер «давно не выгружали JSON» (iOS может вычищать хранилище PWA при простое — экспорт это наш бэкап).
- [ ] **Версия схемы данных** — записывать `schemaVersion` в IndexedDB и в экспорт; заложить миграции Dexie.

## P0 — награды (доводим механику)

- [ ] **Пороги под шкалу 28** — текущие 50/150/300 пересчитать под реальные недельные/накопительные баллы.
- [ ] **«Забрать награду»** — отметка «выдана», persist в IndexedDB (сейчас награда только «заработана», без погашения).
- [ ] **Определиться: недельные vs накопительные** — сейчас награды считаются от all-time; решить и явно задокументировать.

## P1 — родительский контроль и правки

- [ ] **«Замочек» на принятых отметках** — визуально показывать лок (сейчас просто disabled).
- [ ] **Правка принятого за прошлые дни** — уже разлочивается в родрежиме; довести UX (выбор даты, снятие/добавление, пересчёт метра).
- [ ] **Редактируемые дети/задачи/цели** — вынести из констант в IndexedDB (сид из дефолтов), чтобы менять без пересборки.
- [ ] **Аватар: выбор из вариантов + загрузка фото** — хранить фото в IndexedDB, а не в исходниках.

## P1 — статистика и обзор

- [ ] **Экран истории/статы** — по неделям/месяцам, на ребёнка (данные уже есть в `completions`).
- [ ] **Экспорт за произвольный период** (сейчас «всё» и «текущий месяц»).

## P2 — полировка UX/визуал

- [ ] **Иконка PWA** — переопросать красивее (сейчас монстер-трак-плейсхолдер), splash-скрин.
- [ ] Анимации метра/машинок, лёгкий звук/хаптика на «Принять».
- [ ] Разные цвета плиток закреплены за категориями (готово), довести иконки.
- [ ] Настройка ширины «планшетного» контейнера, тёмная/светлая тема (сейчас только тёмная).

## P2 — техдолг под будущий переезд на бек

- [ ] **Изолировать слой данных** — весь доступ через репозитории/композаблы (частично сделано), чтобы подмена IndexedDB→API была точечной.
- [ ] **Типизация модели** (перейти на TS или JSDoc-типы для `completion`, `child`, `task`, `reward`).
- [ ] Юнит-тесты на недельную математику и репозиторий (сейчас тестов нет).

## Definition of Done для фазы 1

Приложение остаётся 100% локальным и оффлайн, но: данные защищены (сброс/бэкап/версии), награды доведены, родрежим правит историю, аватары/каталог редактируемы без пересборки. Слой данных изолирован — готов к переезду на бек.
