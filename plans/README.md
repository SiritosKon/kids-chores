# Планы развития — «Домашние дела детей»

Живой набор планов по проекту. Пишем и уточняем итеративно.

## Где мы сейчас (baseline)

MVP для теста на **одном устройстве** (iPad), на реальных детях автора.

- Стек: Vue 3 + Quasar + Vite, стейт в **IndexedDB (Dexie)**, PWA, хостинг GitHub Pages.
- Дети, задачи, награды, пароль родрежима — **константы в коде**.
- Гоалметр недельный (Пн–Вс, цель 28), «сброс» вычисляемый (без таймеров).
- Единый список задач, чекбокс на каждого ребёнка, отметки за день с локом принятого.
- Родрежим (клиентский пароль): экспорт/импорт JSON, разлочка правки.
- Весь стейт **локальный**; бэкапа/синка между устройствами нет — только ручной JSON.

1. Дополняем и приоритизируем фазу 1 → делаем быстрые улучшения сегодня.
2. Проектируем целевую архитектуру (фаза 2), рисуем C4 (Context / Container).

## Принципы

- **Локальный стейт — временный.** Всё проектируем так, чтобы источник правды позже переехал на бэк без переписывания UI (слой доступа к данным изолирован: `db/completionsRepo`, композаблы).
- **JSON export/import — контракт миграции.** Его формат = черновик серверной модели.
- **Данные детей чувствительны.** Приватность и бэкап — первого класса (см. фазы 2–3).
