# 01 — Бэклог фич

Что ещё можно добавить. Разделено по тому, **нужен ли бэкенд**. Приоритеты: P0 — высокая ценность/скоро, P1 — важно, P2 — приятно.

## A. Работает локально (без бэка) — можно делать сейчас

Ключевая предпосылка: вынести дети/задачи/награды/настройки из констант в IndexedDB (сид из дефолтов),
чтобы их можно было редактировать без пересборки. Это разблокирует почти весь список ниже.

| Фича | Приоритет | Заметки |
|---|---|---|
| **Родрежим: редактирование наград** | P0 | Имя, стоимость, иконка; добавить/удалить/переупорядочить. Стоимость — снимок в списаниях уже есть, история не поедет. |
| **Родрежим: редактирование задач** | P0 | Имя, иконка, баллы, вкл/выкл, порядок. `active:false` вместо удаления (не ломать историю). |
| **Родрежим: редактирование детей** | P0 | Имя, аватар (выбор/загрузка фото в IndexedDB), недельная/копилочная цель. Добавить/удалить. |
| **Настройка бонуса** | P0 | Вкл/выкл «доп. балл за все задачи дня», размер бонуса, какие задачи входят в «все». Сейчас захардкожено (+1 за 3 задачи). |
| **Онбординг / стартовый экран** | P1 | Первый запуск: мастер «добавь детей → задачи → награды». Пустое состояние вместо дефолтных Тимофей/Даниил. |
| **Назначение задач на ребёнка** | P1 | Не все задачи для всех: у каждой задачи — для кого показывать (сейчас общий список на обоих). |
| **Экран статистики/истории** | P1 | По неделям/месяцам на ребёнка: сколько заработал/потратил, стрики, графики. Данные уже в `completions`/`spends`. |
| **Выдача награды (fulfillment)** | P1 | Пометка «награда выдана по факту» отдельно от списания баллов; список «к выдаче». Сейчас списание = сразу «куплено». |
| **Штрафы / отрицательные баллы** | P2 | Родрежим: снять баллы за проступок (запись в леджер со знаком минус). |
| **Геймификация** | P2 | Стрики (N дней подряд все задачи), уровни, ачивки. Движок начислений на клиенте. |
| **Локализация (i18n)** | P2 | Сейчас только ru. Quasar + языковые паки; вынести строки. |
| **Темы/звуки/анимации** | P2 | Светлая тема, выбор палитры, звук/хаптика на «Принять» и покупку (конфетти уже есть). |
| **Бэкап-напоминания / автоэкспорт** | P1 | iOS может чистить хранилище PWA — напоминать/предлагать выгрузку JSON регулярно. |
| **Правила копилки** | P2 | Настройка шага копилки (сейчас 50), режим «недельный сброс vs накопительный». |

## B. Нужен бэкенд (см. `02-backend-architecture.md`)

| Фича | Зачем бэк |
|---|---|
| **Аккаунты + вход (Google/Yandex SSO)** | Идентификация семьи, привязка устройств. |
| **Синхронизация между устройствами** | Родитель с телефона, дети с планшета — общий стейт. |
| **Несколько опекунов** | Оба родителя/бабушки в одной семье, роли. |
| **Push-уведомления и напоминания** | «Сделай дела», «неделя закрывается» — нужен серверный планировщик + push-канал. |
| **Надёжное хранение / бэкапы** | Не зависеть от локального кеша браузера. |
| **Магазин наград с балансом на сервере** | Единый баланс на всех устройствах, античит. |
| **Аналитика для родителя (облачная)** | Тренды по семье, дашборд. |
| **Подписка Pro** | Облако/семьи/приватность за деньги (биллинг). |

## Рекомендация по порядку

1. **Сейчас (локально):** вынести конфиг в IndexedDB → редактирование наград/задач/детей + настройка бонуса + онбординг. Это даёт «настраиваемое под любую семью» приложение ещё до бэка.
2. **Потом:** статистика, назначение задач, fulfillment наград.
3. **Затем (с бэком):** аккаунты + SSO + синк, дальше уведомления и мультиопекун.

> Технически всё «локальное» уже готово к переезду: доступ к данным изолирован в репозиториях (`completionsRepo`, `spendsRepo`, `walletRepo`, `useBalances`), поэтому подмена IndexedDB → API будет точечной.
