# Research — развитие «Домашние дела детей»

Аналитика по развитию проекта из локального MVP (одно устройство, IndexedDB, PWA на GitHub Pages)

Живёт в отдельной ветке `research` (в `main`/`ios` не мержится). Это проектные заметки, не код.

## TL;DR (главные выводы)

1. **Фичи.** Большая часть ближайшего бэклога (редактирование наград/детей/задач, онбординг, настройка бонуса, статистика) **делается локально, без бэка** — можно двигать прямо сейчас на текущей архитектуре, вынеся конфиг из кода в IndexedDB. Бэк нужен только для синка между устройствами, аккаунтов и уведомлений.

2. **Бэкенд.** Нагрузка **крошечная** → микросервисы не нужны. Ядро — **модульный монолит** (NestJS) + PostgreSQL + Valkey + объектное хранилище; доменные сущности на сервисы не дробим — при нашем размере это не нужно; то, что действительно отделяется, выделяем сразу: **Notifications — отдельный сервис с первого дня**, Analytics — по триггеру. Брокер на нашей нагрузке не обязателен, но **закладываем его с первого дня** — ради масштабирования и отработки событийной архитектуры: **Valkey** (форк Redis, BSD, бесплатно — контейнер на той же VM вместо платного managed Redis), Streams с consumer groups, события через transactional outbox в Postgres, BullMQ для расписаний. **Kafka не берём.**

3. **Вход.** RU и EU — отдельные сайты, в каждом стандартный вход через провайдера: RU — **Яндекс ID и VK ID** (закрывает ч. 10 ст. 8 149-ФЗ), EU — **Google**. Своих паролей, email-кодов и SMS нет. **Минимум ПДн:** минимальный scope, храним только HMAC идентификатора провайдера, без email, имени и телефона; IP не логируем. Свой тонкий слой в монолите, сессии — httpOnly-cookie, хранятся в Valkey.

4. **Регионы.** RU и EU — **два независимых развёртывания** (свои БД, домены, ключи, бэкапы, логи). **Первым поднимаем EU:** Hetzner (VM + Docker Compose, Postgres и Valkey на VM, WAL-G), фронт на Cloudflare Pages, домен `.app`, nginx. RU — потом, на Yandex Cloud; с 01.07.2025 данные граждан РФ нельзя даже первично записывать за рубежом, фронт RU — тоже из RU-облака. Staging нет.

5. **ПДн/фото.** Оператором ПДн мы остаёмся в любом случае, поэтому цель — минимум: без контактов родителя, без IP в логах, данные семьи на сервере в открытом виде под изоляцией семей. **Фото детей не собираем** — набор аватарок. Картинки вариантов наград — не ПДн: хранилище контура + CDN. Юридические обязанности — отдельным этапом.
